Actions

Preview is real. Batch processing uses a bounded worker queue with cancel support. ZIP export is live, and this polish pass adds safer destructive actions, improved drag-and-drop, and clearer batch diagnostics.

Phase 7

Refresh preview

Reruns the main-thread preview compositor using the currently selected source image, overlay, and mode.

Process batch to PNGs

Runs real PNG compositing through a bounded queue. Worker mode keeps the UI more responsive, and cancellation can stop queued work cleanly.

Build ZIP

Packages the currently prepared PNG outputs into a real ZIP archive and starts a download. You can also re-trigger the most recent ZIP download without rebuilding it if the archive is still current in memory.
